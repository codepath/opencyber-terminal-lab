Welcome — this is your workstation.

You are logged in as the "student" user on a Linux machine. This is your
sandbox for the Terminal + SSH Lab. Nothing you do here can hurt your real
computer, so experiment freely.

In your home directory (~/):

  README.txt   <- you are reading it
  keys/        <- SSH access keys you've been given for the lab servers
  notes/       <- a few of your own files, to practice looking around

You'll use the keys to SSH into two servers — no password needed:

  - the webadmin server  (Part 2: get on it, then investigate it)
  - the deploy box       (Part 3: get on it on your own, then triage it)

  Example:  ssh -i ~/keys/webadmin_key webadmin@localhost

Follow the lab instructions here:
  https://github.com/codepath/opencyber-terminal-lab

Tip: if you ever feel lost, run `pwd` (where am I) and `ls` (what's around me).
